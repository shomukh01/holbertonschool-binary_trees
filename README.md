# C - Binary Trees

## Description
This project introduces binary trees in C, including how to create nodes and work with basic tree structures.

## Requirements
- Ubuntu 20.04 LTS
- gcc -Wall -Werror -Wextra -pedantic -std=gnu89
- Betty style

## Files
- binary_trees.h: Header file with structure and prototypes
- 0-binary_tree_node.c: Function to create a new node

## Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o binary_trees

## Usage
Functions can be tested using example main files provided in the project.
